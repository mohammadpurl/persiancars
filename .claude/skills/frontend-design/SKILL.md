# Frontend Design Rules

* Use an 8px spacing system
* Prefer whitespace over visual clutter
* Use cinematic dark gradients
* Avoid generic Tailwind appearance
* Use premium typography hierarchy
* Use glassmorphism carefully
* Avoid too many borders
* Mobile-first always
* Keep layouts clean and breathable
* Use subtle motion only
* Prioritize performance
* Use reusable section components
* Avoid oversized shadows
* Use smooth rounded corners
* UI should feel like Tesla + Linear + Apple
* Every section must have a clear CTA
* Avoid dense Iranian-style layouts
